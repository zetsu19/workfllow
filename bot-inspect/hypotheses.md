# Урьдчилан бүртгэсэн таамаглалууд (pre-registration)

Бүртгэсэн огноо: 2026-10-17. Энэ файлыг commit хийсэн цагаас хойш өөрчилсөн бол шинэ commit-оор, түүхийг үлдээн өөрчилнө.

## Өгөгдөл
- Эх сурвалж: hub-ийн өдрийн тайлан (`~/hub/data/reports/*.json`), `ideas[]`, simulate-ийн `r`.
- **In-sample (таамаглал гаргахад ашигласан):** тайлан 2026-09-28 … 2026-10-16 (цонх 10-16 06:00 GMT+8 хүртэл).
- **Forward (шалгалтад ашиглах):** тайлан **2026-10-17-аас хойших** (`--since 2026-10-17`). Үүнээс өмнөх өгөгдлөөр шийдвэр гаргахгүй.
- Simulate нь M1 баар, LIMIT entry-д хүрсэн, TP1 эсвэл SL түрүүлсэн, нэг бард хоёулаа бол SL. **Спрэд, комисс орсонгүй** (gross).
- `t` талбарын цагийн бүс: тайлангийн `window.tz` = GMT+8 гэж үзэв (БАТАЛГААЖААГҮЙ, эхний шалгалтаар тодруулна).
- Idea-ууд bot хооронд давхардсан байж болно, бие даасан биш. Статистикт өдрөөр нь блок болгон bootstrap хийнэ.

## Таамаглал (SMC engine: `SMC M1` + `SMC M5`, зөвхөн R-тэй idea)

**H1 - чиглэл.** Дундаж R(bull) > дундаж R(bear).
In-sample: bull +0.05R (n=414, win 28%), bear -0.19R (n=456, win 21%).
Forward шалгалт: нэг талт зөрүү, өдрийн блок bootstrap, чиглэл бүрд n >= 250.

**H2 - цагийн сесс (hub-ийн цаг).**
A = {00,01,02,03}: in-sample n=181, дундаж -0.41R.
B = {15,16,18,21}: in-sample n=145, дундаж +0.41R.
Forward: R(B) - R(A) >= +0.30R, A-д дундаж R < 0; цагийн багц бүрд n >= 100.
(Цагийн багцыг in-sample өгөгдлөөс ХАЙЖ сонгосон, тиймээс сул нотолгоо. Forward-д л хүчинтэй.)

**H3 - V6 одны оноо (V6 engine, `V6 3★`, `V6 4★`, `V6 5★`).**
Дундаж R(3★) - дундаж R(4★ ба 5★) >= +0.30R.
In-sample: 3★ -0.47R (n=84), 4★+5★ -0.88R (n=260).

**H4 - зардал.** SMC-ийн спрэд 0.55-ийн дараах дундаж R < 0 (ямар ч дэд бүлэггүй).
In-sample gross: -0.077R (n=870); `--spread 0.55`-аар цэвэр R-ийг тооцно.

## Дүрэм
- 4 таамаглал тул Bonferroni: α = 0.0125 / таамаглал.
- Таамаглал бүрийг **нэг л удаа**, дээрх n-д хүрмэгц шалгана. Завсарт хараад зогсоохгүй.
- Үр дүнг (баталсан ч, үгүйсгэсэн ч) энэ файлд нэмж бичнэ.
- Forward баталгаагүй бол demo/live аль ч тохиргоог өөрчлөхгүй. Баталсан ч гэсэн хүний зөвшөөрөлтэйгээр, тусдаа demo arm дээр түрүүлж.
